# Safe Web Search Skill for OpenClaw

一个为 OpenClaw AI 助手设计的安全互联网搜索技能，允许在本地部署的 OpenClaw 根据用户指令安全地访问互联网收集资料。

## 🛡️ 安全第一的设计理念

本技能的核心设计原则是**安全性优先**，确保在提供互联网访问能力的同时，最大程度地保护用户和系统的安全。

### 核心安全特性
- **多层内容过滤**：自动过滤恶意、非法或不适当内容
- **智能网站限制**：基于风险评级的网站访问控制
- **严格数据验证**：验证所有输入和输出数据的完整性
- **使用行为监控**：实时监控和限制异常使用模式
- **隐私保护设计**：不收集、不存储用户隐私信息

## 📦 快速开始

### 安装
```bash
# 进入技能目录
cd skills/safe-web-search

# 运行安装脚本
chmod +x install.sh
./install.sh
```

### 基本使用
```bash
# 执行安全搜索
./safe_search.py "Python 编程教程"

# 限制搜索结果数量
./safe_search.py "机器学习" --max-results 5
```

## 🏗️ 系统架构

### 安全层设计
```
用户请求 → 输入验证 → 安全检查 → 内容过滤 → 安全输出
      ↓         ↓         ↓         ↓         ↓
  合法性检查  风险评估  网站验证  恶意代码检测  隐私保护
```

### 组件说明
1. **安全验证器**：验证所有输入和请求的合法性
2. **内容过滤器**：多层过滤不安全内容
3. **访问控制器**：管理网站访问权限和频率限制
4. **监控记录器**：记录所有操作用于审计和安全分析

## ⚙️ 配置说明

### 安全级别
- **low**：基本过滤，适合可信环境
- **medium**：标准过滤，平衡安全与可用性（默认）
- **high**：严格过滤，最大程度的安全保护

### 主要配置项
```json
{
  "security_level": "medium",
  "max_results_per_search": 10,
  "daily_search_limit": 50,
  "require_https": true,
  "blocked_domains": [...],
  "trusted_sources": [...]
}
```

## 📊 监控和审计

### 搜索统计
技能会自动记录：
- 每日搜索次数和使用趋势
- 被阻止的访问尝试
- 安全警告和异常事件

### 安全报告
定期生成安全报告，包括：
- 安全策略执行情况
- 风险事件统计
- 使用模式分析

## 🚨 安全响应

### 异常检测
技能会自动检测以下异常：
- 高频搜索请求（可能的滥用）
- 尝试访问已知恶意网站
- 返回内容包含可疑代码
- 配置文件的意外修改

### 应急措施
检测到严重安全威胁时：
1. 立即停止当前操作
2. 记录详细事件信息
3. 通知系统管理员（如果配置）
4. 进入安全锁定模式（可选）
