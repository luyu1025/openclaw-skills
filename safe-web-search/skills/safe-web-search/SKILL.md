# Safe Web Search Skill

一个安全的互联网搜索技能，允许 OpenClaw 根据用户指令访问互联网收集资料，同时确保网络安全和本地安全。

## 功能特性

### 🔒 安全特性
- **内容过滤**：自动过滤恶意、非法或不适当内容
- **网站限制**：限制访问高风险网站类型
- **数据验证**：验证返回数据的完整性和安全性
- **使用限制**：防止滥用和过度访问
- **隐私保护**：不收集或存储用户隐私信息

### 🔍 搜索功能
- **智能搜索**：根据用户指令进行精准搜索
- **多源获取**：从多个可靠来源获取信息
- **内容提取**：提取网页核心内容，去除广告和噪音
- **结果整理**：整理搜索结果，提供清晰摘要

### ⚙️ 配置选项
- **安全级别**：可调整的安全过滤强度
- **网站白名单**：自定义允许访问的网站
- **搜索限制**：设置每日/每次搜索限制
- **内容类型**：指定搜索的内容类型

## 安全策略

### 1. 内容过滤规则
- 过滤包含恶意代码的网页
- 屏蔽成人内容和不适当材料
- 阻止访问已知的恶意网站
- 验证 SSL/TLS 证书有效性

### 2. 访问限制
- 限制访问频率（防止 DDoS 攻击）
- 限制单次搜索返回结果数量
- 限制访问特定高风险域名
- 监控异常访问模式

### 3. 数据保护
- 不存储用户搜索历史
- 不收集个人身份信息
- 加密传输搜索请求
- 定期清理临时数据

## 使用示例

## 故障排除

### 常见问题
1. **搜索无结果**：检查网络连接，或调整搜索关键词
2. **访问被拒绝**：目标网站可能被安全策略阻止
3. **内容不完整**：网页结构可能不支持自动提取

### 安全警报
如果检测到以下情况，技能会自动停止：
- 尝试访问已知恶意网站
- 异常高频的搜索请求
- 返回内容包含可疑代码
